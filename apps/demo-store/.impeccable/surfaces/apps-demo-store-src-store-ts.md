# Surface: Ovalwork Running (demo store)

Scope: apps/demo-store home/catalogue and product pages. Visitor mode: Persuade (shop). Audience: hackathon judges watching the agent buy, and the agent itself reading product facts. Job: make a believable specialist running shop whose product facts are unmistakable, because Provenant snapshots them. Constraints: JSON-LD and data-attr/data-price hooks stay exact; product images stay synthetic (rendered by png.ts) and are labelled as demo; no invented reviews, ratings, customers or claims; the store must not look like PayPal.

## Direction contract

THESIS: The shop is its stockroom wall. Refuses the category default of a giant hero shoe over a white filter grid.
OWN-WORLD: One committed box colour (signal orange-red box board) owning whole regions; printed white box-end labels with black ruled fields; condensed industrial label type for names and big size numerals; tabular mono only for SKU/price/data. Box ends stack in a grid with thin shadow gaps like real shelving.
STORY: The visitor sees a full wall of boxes, each label stating SKU, colour, size, style, price, delivery; understands this shop prints exactly what you get; picks a box; the product page opens the box (lid lifted, shoe on tissue, the label fields big).
FIRST VIEWPORT: Narrow top bar (wordmark left, search centre, demo flag right); then the wall: 4-up box ends at desktop, each ~300px wide, product image in the box mouth, label below; search filters the wall live. No hero copy block; one line of headline set on the shelf header.
FORM: Stockroom wall, candidate 3 of 7; seed key 9564208c. Raises: numbered plates (from couture atelier): each box carries a bay number in sequence; every option present, chosen struck (from cathode gauze): size rail shows all sizes, stocked ones stamped, others ghosted.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
